# Source Map

Use these official sources as the frontier baseline.

- OpenAI Agents guide
  - `https://platform.openai.com/docs/guides/agents`
  - Why: current official guidance for agentic workflows, tool use, and handoffs.

- LangGraph docs
  - `https://langchain-ai.github.io/langgraph/`
  - `https://langchain-ai.github.io/langgraph/concepts/persistence/`
  - `https://langchain-ai.github.io/langgraph/concepts/human_in_the_loop/`
  - Why: current reference for graph-based orchestration, persistence, interrupts, and durable execution.

- AutoGen stable docs
  - `https://microsoft.github.io/autogen/stable/`
  - `https://microsoft.github.io/autogen/stable/user-guide/core-user-guide/design-patterns/index.html`
  - Why: current reference for multi-agent conversation patterns and runtime design patterns.

- CrewAI docs
  - `https://docs.crewai.com/en/concepts/agents`
  - `https://docs.crewai.com/en/concepts/flows`
  - Why: current reference for crew/task separation and evented flow patterns.

- Model Context Protocol
  - `https://modelcontextprotocol.io/`
  - `https://modelcontextprotocol.io/specification/2025-03-26/roots`
  - Why: current standard for tool/resource boundaries and host-controlled capability exposure.
