# 临时测试：内丹法样例1重拆解

> 状态：临时测试记录，不是真相源。
> 说明：这是按已对齐后的 `neidan-method` 重跑的**一轮完整闭环**，不是多轮评测，也不是十层摘要。这里的“层”只表示轮内下钻深度。
> 目的：重新拆解“完全不会写作的小孩，想写一部人类蛋生的爆款小说”这个样例，验证新 skill 是否能把愿望推进为完整产物，而不是停在说明书。

## 0. 原始例子

一个完全不会写作的孩子，只有一句话想法：假如某个平行宇宙中人类是蛋生的，会怎么样？他想写出一部爆款小说。

## 1. 任务业

```text
原始愿望: 写一部“人类蛋生”的爆款小说
最终目标: 一部可连载、可试读、可根据反馈迭代的商业小说
当前阶段产物: 项目圣经 v2 + 黄金三章 + 第一章完整正文 v1 + 试读包
验收对象: 目标读者是否能复述卖点、理解主角困境、感到追读冲动
非目标: 不在本轮证明真实爆款，不把概要当交付，不把样章当最终结果
已知约束: 用户不会写作；只能先用 AI 补能力；“爆款”只能用代理指标描述
风险等级: 中
反馈渠道: 目标读者试读、AI 评审、评论、平台数据
```

## 1.5 复用扫描

- 直接复用：网文开头钩子、黄金三章、主角困境、章节末悬念、试读问卷。
- 改造复用：爆款代理指标、设定驱动、世界规则先行、人物选择压力。
- 仅作参考：蛋生/胎生的生物差异、社会分层、继承制度、出生前交易。
- 忽略：只做世界观设定说明、不进入正文的材料整理。

## 2. 概念图

| 概念 | 角色 | 当前清晰度 | 是否阻塞执行 | 是否阻塞验收 |
|---|---|---|---:|---:|
| 爆款 | 质量目标 | 模糊 | 是 | 是 |
| 小说 | 产物类型 | 模糊 | 是 | 是 |
| 蛋生 | 核心设定 | 模糊 | 是 | 否 |
| 好看 | 审美判断 | 模糊 | 是 | 是 |
| 不会写作 | 能力缺口 | 清晰 | 是 | 否 |

## 3. 下钻层

### 3.1 爆款

- 机制：读者愿点开、留下、追更、分享、付费或评论。
- 动作：标题/简介吸引、开头设异常、章末留未解问题、主角有主动选择、设定可复述。
- 信号：3 分钟内能说出卖点；前 1000 字出现 2 个以上未解悬念；章节末有追更理由。
- 失败信号：只有设定说明，没有事件；只有“世界很新”，没有主角困境。
- 边界：爆款不能被内部自评证明，只能用代理指标和外部反馈逼近。
- 量化代理：点击意愿、追读意愿、复述准确率、章末悬念记忆率、分享意愿。

### 3.2 小说

- 机制：故事由人物欲望、障碍、变化和代价串联，不是知识说明书。
- 动作：确定类型、视角、篇幅、卷结构、更新节奏、主线目标。
- 信号：每章都有目标、阻碍、变化、悬念。
- 失败信号：像设定集、像提案、像说明文，不像连续叙事。
- 边界：本轮只需完成开篇和项目骨架，不必证明整本书完结。

### 3.3 蛋生

- 机制：出生过程被制度化，蛋壳编号、孵化权限、血缘、阶级和继承发生绑定。
- 动作：把“蛋生”拆成孵化制度、蛋权、编号、亲子关系、出生前交易、身体伦理、犯罪风险。
- 信号：同一枚蛋在不同阶层有不同价值；救蛋、销毁蛋、偷蛋都会引发代价。
- 失败信号：蛋生只是奇观，没有改变主角命运。
- 边界：蛋生要进入场景和冲突，不可只停留在百科式设定。

### 3.4 好看

- 机制：信息差、欲望阻碍、情绪回报、反转、选择压力共同作用。
- 动作：在开头制造异常，在章末制造未完成问题，在每章让主角做选择。
- 信号：读者能说出“我想知道接下来发生什么”。
- 失败信号：堆设定、慢热过长、没有动作推进。
- 边界：审美判断只能做可观察代理，不可假装成真理。

## 4. 原子动作

- 检索网文开头套路、题材定位、设定驱动、试读问题。
- 比较不同开头钩法和章末悬念法。
- 归纳蛋生设定可产生的制度冲突。
- 选择一个核心主角和核心对手。
- 生成项目圣经、黄金三章和第一章正文。
- 修改每个质量词，使其落到信号和阈值。
- 校验是否保留最终目标，没有缩成样章。
- 记录哪些反馈只能来自真实读者。

## 5. 临时法

**法名：蛋生网文起步法 v1**

```text
1. 先保留最终目标：要做的是可连载、可试读、可迭代的商业小说，不是概要。
2. “爆款”只拆成代理指标：点开、留下、追更、分享、付费/评论。
3. “蛋生”必须先变成制度，再变成冲突，再变成场景。
4. “好看”必须落到读者行为和章节行为，不能只留在抽象评价里。
5. 每章都要有目标、阻碍、变化和悬念。
6. 当前阶段必须同时产出项目圣经、章节结构、第一章正文和试读问题。
7. 任何爆款结论在没有真实读者反馈前都只能写成候选判断。
```

## 6. 完整产物

### 6.1 项目圣经 v2

**书名**：《第七孵化所》

**一句话卖点**  
在人类由蛋孵化、蛋壳编号决定命运的世界里，下城孵化工林砚发现自己的出生编号被上城贵族篡改，而一枚即将被销毁的白蛋，可能藏着他被偷走的出生真相。

**目标读者**  
喜欢设定流、阶级逆袭、秘密身份、强开头钩子的网文读者。

**核心冲突**  
林砚如果救下白蛋，就可能毁掉那个“替代者”；如果按下销毁确认，他就永远只是一名被偷走命运的人。

**叙事承诺**  
每章都让蛋生制度带来新的代价，不把蛋生只当背景。主角会持续用底层规则反打上层规则。

**爆款代理指标与局限**  
可复述卖点、开头留存、章末追更意愿、转述率、试读评分；这些只代表“更值得试读”，不代表真实爆款。

**世界规则**
- 蛋壳编号决定阶级、教育与继承资格。
- 下城负责处理畸形蛋和污染蛋。
- 蛋权争议决定救蛋是否构成犯罪。
- 出生前交易可篡改命运，但会留下旧码痕迹。

**主要人物**
- 林砚：第七孵化所夜班记录员，想找回自己的身份。
- 沈阙：第九家族继承监管人，制度受益者，不是纯粹恶人。
- 白蛋内意识：可能是证人，也可能是“偷走林砚人生”的另一个孩子。

### 6.2 黄金三章

**第 1 章**  
夜班守则、白蛋、旧码 0717、销毁确认、蛋壳内传来林砚名字。目标：制造规则钩、身份钩、关系钩。

**第 2 章**  
林砚藏起白蛋，发现蛋壳内侧有母亲留下的血印，意识到自己可能也是被调包的一部分。

**第 3 章**  
全城搜捕偷蛋者，白蛋第一次传出心跳并喊他“哥哥”，主角被迫决定是继续隐瞒还是追查真相。

### 6.3 第一章完整正文 v1

第七孵化所的夜班守则第一条：听见蛋壳里有人哭，不要回应。

林砚第一次听见哭声，是在凌晨三点十七分。

保温灯一盏盏暗下去，三百枚灰壳蛋像沉默的石头排在铁架上，只有尽头的销毁炉还亮着红光。夜班最怕的不是累，是怕灯一灭，谁也分不清哪一枚蛋在发热，哪一枚已经开始污染。

炉门前放着一枚白蛋。

白蛋不该出现在下城区。它的壳面细得像玉，编号用金线烧在壳纹里，代表上城区第九家族的继承序列。这样的蛋从产房出来就会被送进恒温塔，由三十六名孵化师轮班照看，连灰尘都没有资格落上去。

可现在，它被贴上了红签。

红签的意思是：畸形、污染、无权出生。

林砚把登记册翻开，指尖停在那串金线编号上。编号下面还有一行被刮掉的旧码，像有人用刀背把一段命运硬生生磨平，只剩最后四位。

0717。

他下意识摸了摸后颈。那里有一块很早就被烙上的数字，医生说那只是下城孩子常见的识别印，免得抱错、领错、换错。他从来没怀疑过，直到此刻，指腹下的烙印像被火重新点了一下。

也是 0717。

销毁炉发出低沉的预热声，铁门缓缓张开。按规程，夜班记录员只需要核对红签、按下确认、在登记册上写“污染蛋已销毁”。明早清洁工会把炉灰扫进黑桶，连同今晚发生过的一切一起送去填埋。

林砚的手已经放在确认钮上。

只要按下去，这一切就结束了。

那枚白蛋会变成灰。灰会和别的灰混在一起。没人知道它今晚曾经短暂地活过。没人会问一个下城记录员在销毁炉前看见了什么。灰壳人最值钱的本事，就是学会没看见。

他正要用力，蛋壳里的哭声忽然停了。

接着，一个很轻的声音从白壳里传出来，像贴着耳朵说话。

“林砚。”

他猛地后退，撞翻了记录灯。红光擦过墙面，夜班守则第二条被照得像一道判决：

未授权回应蛋内意识者，以偷生罪论处。

走廊外传来脚步声。

巡夜孵化师比平时早了十分钟。

林砚一把合上登记册，盯着白蛋上的红签，忽然明白一件事：如果他按下确认钮，明天他仍然是第七孵化所的灰壳记录员，0717 只是他脖子后面一块丑陋的烙印。

可如果他不按，他偷走的就不是一枚蛋。

是上城区第九家族的继承人。

也是他自己的出生真相。

门外的脚步声停了。

有人在门边低声问：“林砚，炉门开了吗？”

他没有立刻回答。

因为这一刻，他突然意识到，自己要选的不是救不救一枚蛋，而是要不要承认：他从来就不是一个只负责销毁别人的人。

### 6.4 试读包

**试读问题**
1. 你能不能用一句话复述这个故事讲什么？
2. 你在第几段知道了主角的困境？
3. 你最想知道白蛋是谁？
4. 你是否愿意继续读下一章？

**通过阈值**
- 60% 以上试读者能复述“蛋壳编号决定命运，主角发现白蛋和自己编号有关”。
- 平均追读意愿不低于 7/10。
- 至少 1 个问题能稳定引出“母亲/替代者/身份”三个方向中的一个。

## 7. 验收结果

| 指标 | 结果 | 判断 |
|---|---|---|
| 原愿保持 | 通过 | 没有缩成样章说明书 |
| 概念下钻 | 通过 | 爆款、小说、蛋生、好看都下钻到机制/动作/信号 |
| 原子动作 | 通过 | 有检索、比较、生成、修改、校验 |
| 完整产物 | 通过 | 项目圣经、三章、完整正文、试读包都给出 |
| 量化验收 | 部分通过 | 代理指标完整，但仍只是代理 |
| 真实爆款证明 | 不通过 | 也不应由本轮内部自证 |

## 8. 法更新说明

- 轮不是层；一轮必须有完整产物和验收。
- 爆款只能先写代理指标，不能直接当事实。
- 蛋生必须进入制度、冲突和场景。
- 好看要落到章节动作和读者行为，不可停在审美标签。
- 需要人判断的产物必须完整输出，不得节选。

## 9. 观察到的失败模式

- 如果只给设定，不给正文，就会退回说明书。
- 如果只给内部评价，不给试读问题，就无法验证追读感。
- 如果把蛋生当奇观，不当制度，就没有故事压力。
- 如果把爆款当真理，就会错误缩小目标。
