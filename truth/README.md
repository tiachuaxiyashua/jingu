# Truth

`truth/` 是 Jingu 项目的当前真相空间。它与 `docs/` 平级，不从属于 `docs/`。

## 当前真相源

唯一入口：[当前真相源：人工智能软件社会相业架构](./00-当前真相源-人工智能软件社会相业架构.md)。

`00` 同时承载项目总纲、核心目的、架构入口、运行机制和当前验证结论。后续讨论、实现、评审和迁移都必须先服从它。

当前判断：

- `人`：愿望、品味、授权、责任和最终裁决的源头。
- `相`：一切可保存、可引用、可呈现、可迁移的稳定存在。
- `业`：一切相之变化必须通过的可验证工作契约。
- `因 / 愿 / 缘 / 律`：分别表达因相张力、目标所求、上下文条件和边界律。
- `位 / 法 / 行者`：分别表达职责位置、能力方法和承接业的代理。
- `果 / 证 / 藏`：分别表达成果、可信证和可复用沉淀。
- `业网`：多个业通过引用、评审、拒收、修正、仲裁和升级形成的关系投影。

## 历史过时文档

除 `00-当前真相源-人工智能软件社会相业架构.md`、`README.md` 和 `AGENTS.md` 外，所有旧总纲、旧讨论、旧评审、旧测试都应归档到 `历史过时文档/`。

这些文档只作为概念来源和历史脉络，不再作为当前重构判断依据。

## 使用方式

- 后续讨论未来产品方向、对象模型、文件协议、编排哲学和重构策略时，先读当前真相源。
- 若需要追溯概念来源，再读 `历史过时文档/`。
- 不再让多份脑暴或阶段性架构同时争夺真相源地位。
- 若未来推翻当前真相，应先更新或替换当前真相源，再迁移旧文档到历史过时目录。
