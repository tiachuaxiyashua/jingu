# Truth

`truth/` 是 Jingu 项目的**当前真相空间**。它与 `docs/` 平级，不从属于 `docs/`。

## 当前真相源

第一入口：[项目总纲：核心目的](./000-项目总纲-核心目的.md)。

总纲规定 Jingu 的最高目标是构建能力补全型 AI harness：让只有粗糙愿望、缺少专业能力的人，也能在 AI、工具、证据、验收和人类裁决的共同作用下，把想法推进为可检查、可迭代、可交付的现实成果。

架构入口：[当前真相源：人工智能软件社会相业架构](./00-当前真相源-人工智能软件社会相业架构.md)。

现有相业架构、后续实验分阶、代码实现和评审标准都必须服从总纲；若术语完整性与能力补全目标冲突，以总纲为准。

当前判断：

- `人`：愿望、品味、授权、责任和最终裁决的源头。
- `相`：一切可保存、可引用、可呈现、可迁移的稳定存在。
- `业`：一切相之变化必须通过的可验证工作契约。
- `因 / 愿 / 缘 / 律`：分别表达因相张力、目标所求、上下文条件和边界律。
- `位 / 法 / 行者`：分别表达职责位置、能力方法和承接业的代理。
- `果 / 证 / 藏`：分别表达成果、可信证和可复用沉淀。
- `业网`：多个业通过引用、评审、拒收、修正、仲裁和升级形成的关系投影；固定路线图不再作为根概念。

- 后续讨论未来产品方向、对象模型、文件协议、编排哲学和重构策略时，先读当前真相源。
