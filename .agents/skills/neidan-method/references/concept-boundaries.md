# 概念边界

## 内丹法本体

内丹法本体的职责是：把低能力、低清晰度、粗糙愿望推进为可执行、可验收、可修正、可沉淀的真实产物。

它不是：

- 只做概念解释。
- 只生成方法说明。
- 只输出阶段性摘要。
- 只靠 AI 自评证明开放世界目标。

## 层

`层` 是一次完整执行内部的递归下钻深度。

例如：

```text
爆款
  -> 追读
  -> 章末悬念
  -> 读者下一章点击意愿
  -> 0-10 分追读评分
  -> 低于 7 分时改写章末问题
```

这叫多层下钻，不叫多轮。即使拆了十层，只要没有完成完整产物、验收、反馈和方法修正，也仍然只是同一轮内部工作。

## 轮

`轮` 是一次完整闭环。最小合格轮必须包含：

1. 重新读取原始愿望，防止目标漂移。
2. 完整拆解关键阻塞概念。
3. 定义概念边界、适用范围、失败条件。
4. 把质量词推进到可观察信号、代理指标、阈值、范例、反例或评分表。
5. 生成本轮临时法。
6. 使用本轮临时法执行任务。
7. 输出本轮完整产物。
8. 用临时法和验收标尺评审完整产物。
9. 记录距离原始愿望的缺口。
10. 分析缺口产生原因。
11. 修正方法或提出方法修正候选。
12. 回到原始愿望，准备下一轮。

少了完整产物或验收，不是一轮；只是分析阶段。

## 完整产物

完整产物是用户可以直接判断、测试、复盘或继续加工的对象。

禁止用这些形式替代完整产物：

- 节选。
- 片段。
- 概要。
- 省略号。
- “略”。
- “其余同上”。
- “为节省篇幅”。
- 只给结构，不给正文或实现。

如果产物太大，必须拆成多个文件或多个明确编号的部分，并保留完整内容。拆分可以，缩水不可以。

## 内部验收与外部反馈

内部验收可以判断：

- 是否满足任务契约。
- 概念是否落到动作、信号、边界。
- 产物是否完整。
- 规则是否真正指导执行。
- 是否存在明显失败模式。

外部反馈用于判断：

- 市场是否接受。
- 审美是否成立。
- 真实用户是否愿意继续。
- 专家是否认可。
- 物理或工程环境是否通过。

不能把 AI 自评、模拟读者、社区经验、专家规范、真实市场数据混为同一等级。

## 内丹法与控制论负反馈

内丹法是执行任务的方法。

控制论负反馈是训练、评测和收敛内丹法的方法。它用于观察内丹法在产物上的误差，再修正内丹法。

二者关系：

```text
内丹法：愿望 -> 法 -> 产物 -> 验收 -> 修正
负反馈评测：使用内丹法 -> 观察产物误差 -> 修正内丹法 -> 再测
```

负反馈评测程序可以存放在引用文件或测试文档中，但不要写成内丹法本体步骤。
