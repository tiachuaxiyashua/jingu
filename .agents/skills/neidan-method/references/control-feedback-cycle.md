# 控制论负反馈闭环模板

本文件用于外部训练、评测和收敛内丹法。它不是内丹法本体。

当用户要求“多轮”“评测”“迭代内丹法”“持续收敛方法”时使用本模板。

## 一轮的合格定义

一轮不是一个步骤，也不是一层概念下钻。一轮必须完成完整闭环：

```text
原始愿望
  -> 本轮完整拆解
  -> 本轮定义与量化
  -> 本轮临时法
  -> 本轮完整执行
  -> 本轮完整产物
  -> 本轮验收
  -> 本轮误差
  -> 本轮方法修正
  -> 回到原始愿望
```

如果只做了概念拆解，没有完整产物和验收，不能称为一轮。

## 多轮收敛规则

1. 每一轮都从原始愿望重新读取，而不是从上一轮结论自然滑下去。
2. 每一轮都必须输出完整产物；不能只输出“改进方向”。
3. 每一轮的修正必须来自产物误差或反馈证据。
4. 每一轮都要区分：
   - 已被产物验证的规则。
   - 只被 AI 自评支持的规则。
   - 需要真实用户、市场、专家、物理或工程反馈的规则。
5. 只有跨多轮稳定有效的修正候选，才允许考虑进入内丹法本体。

## 失败模式

- 把概念下钻层数当成轮数。
- 用结构、概要、样章节选冒充完整产物。
- 没有验收就进入下一轮。
- 只修产物，不修方法。
- 只修方法，不重新执行产物。
- 把 AI 自评当成真实反馈。
- 为节省输出而省略用户需要判断的内容。
