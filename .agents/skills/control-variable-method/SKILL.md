# 控制变量法

控制变量法用于避免“同时改太多东西导致不知道是什么起作用”。它不负责选择价值方向，只负责让比较可复核。

## 适用边界

使用控制变量法时，必须满足：

- 至少存在两个可比较方案。
- 至少有一个要观察的结果指标。
- 能声明哪些条件保持不变。
- 能声明本次只改变哪个变量。

不适用于必须一次性整体改变、无法定义对照或不能观察结果的任务。

## 步骤

### 1. 定义基线

输入：

- 当前方案或原始状态。

动作：

- 写出基线方案。
- 写出基线已知表现。
- 写出基线证据来源。

输出：

- 基线记录。

验收标准：

- 基线必须有名称、内容、证据来源。

### 2. 定义变量

输入：

- 目标变化。

动作：

- 只选择一个本轮变量。
- 写出变量值 A 和变量值 B。
- 明确不改变的条件。

输出：

- 变量表。

验收标准：

- 本轮变量数量必须等于 1。
- 控制条件至少 3 条，或说明为什么不足 3 条。

### 3. 定义指标

输入：

- 目标和风险。

动作：

- 定义主指标。
- 定义副指标。
- 定义失败阈值。
- 定义样本或观察窗口。

输出：

- 指标表。

验收标准：

- 每个指标必须可观察。
- 至少 1 个指标有数值阈值；若无法数值化，必须给替代观察标准。

### 4. 比较与归因

输入：

- A/B 结果或候选表现。

动作：

- 比较主指标。
- 检查副作用。
- 判断差异是否可能由变量造成。
- 标出无法归因的部分。

输出：

- 归因结论。
- 待证项。

验收标准：

- 结论必须包含事实、假设、推论、逻辑链条。
- 不得把相关性伪装成因果确定性。

## 失败信号

- 一轮中改变多个变量。
- 没有基线。
- 没有控制条件。
- 只写“更好”但没有指标。
- 忽略副作用。
- 把不可观察的偏好当作已经验证。

## 与其他法嵌套

- 作为 PDCA 父业的子业时，接收父业 Plan 给出的变量问题，输出比较结果给父业 Check。
- 当变量选择本身来自矛盾或取舍时，应先由辩证法子业显影冲突，再由控制变量法子业验证其中低风险、可观察的事实项。
- 控制变量法子业只能验证事实项，不能替愿主或父业裁决价值方向。
