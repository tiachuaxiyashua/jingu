# 辩证法

辩证法不是折中话术，也不是用漂亮词把冲突抹平。它用于把冲突显影成可讨论、可验证、可裁决的结构。

## 适用边界

使用辩证法时，必须满足至少一项：

- 同一目标内部存在冲突。
- 两个有效方案互相牵制。
- 短期收益和长期收益冲突。
- 质量、成本、速度、风险不能同时满足。
- 多个法给出不同方向。

如果没有真实矛盾，不要强行制造反题。

## 步骤

### 1. 正题

输入：

- 当前主张、目标或方案。

动作：

- 写出正题主张。
- 写出它想保护的价值。
- 写出它成立的条件。

输出：

- 正题卡片。

验收标准：

- 正题必须包含主张、价值、成立条件。

### 2. 反题

输入：

- 正题卡片。

动作：

- 写出与正题真实冲突的反向主张。
- 写出反题保护的价值。
- 写出反题攻击正题的理由。

输出：

- 反题卡片。

验收标准：

- 反题必须是有力反对，不得是稻草人。

### 3. 矛盾显影

输入：

- 正题和反题。

动作：

- 找出无法同时满足的条件。
- 找出冲突影响对象。
- 找出需要人类裁决的价值项。
- 找出可以由实验验证的事实项。

输出：

- 矛盾表。

验收标准：

- 至少 1 个冲突条件。
- 至少 1 个影响对象。
- 区分价值裁决和事实验证。

### 4. 综合候选

输入：

- 矛盾表。

动作：

- 生成综合候选。
- 明确综合方案保留什么、牺牲什么、转化什么。
- 明确仍未解决的风险。

输出：

- 综合候选方案。

验收标准：

- 综合候选不得声称消灭所有矛盾。
- 必须列出代价和残留问题。

## 失败信号

- 把辩证法写成“两个都要”。
- 把价值冲突伪装成技术问题。
- 用弱反题衬托正题。
- 忽略受影响对象。
- 没有给出需要裁决的开放问题。

## 与其他法嵌套

- 作为 PDCA 父业的子业时，接收父业 Plan 或 Act 中的张力问题，输出矛盾表、综合候选和待裁决问题。
- 与控制变量法配合时，辩证法负责区分价值裁决和事实验证；控制变量法只能承接事实验证子业。
- 辩证法子业不能宣告父业完成，只能提交可被父业消费的局部果包。
