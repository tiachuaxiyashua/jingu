# 金箍业树日志查看器

这是一个只读静态网页，用于加载金箍 JSONL 运行日志，并按事件顺序重放业树生长、校验、修复、反馈、父业整合和闭环状态。

## 使用方式

1. 在浏览器中打开 `tools/job-tree-log-viewer/index.html`。
2. 点击“加载 JSONL 日志”。
3. 选择一次金箍运行生成的 `.jsonl` 日志文件。
4. 使用“下一步”“下一关键”“播放”“回到开始”“跳到最终状态”查看业树投影。
5. 在“当前步骤”区域查看本步动作、输入、输出、证据、状态变化和原始 JSON。

## 可观察内容

- 步骤时间线：逐条事件重放，带输入/输出/证据的事件会被标记。
- 业树投影：显示根业、子业、校验业、修复业、反馈业的关系和状态。
- 输入：用户输入、Provider 请求消息、验收请求、父业整合请求、已接收子业果包。
- 输出：AI 响应、子业果包、验收判断、修复响应、父业整合候选、最终输出。
- 证据 / 验收：校验报告、父业重评估、验收路由证据、父业整合证据。
- 状态变化：业编号、父业/子业关系、业树动作、运行步骤、路由动作和失败原因。

## 命令行校验

```powershell
node scripts\validate_job_tree_viewer.js --expect-child-review <日志.jsonl> --expect-parent-integration <日志.jsonl> --expect-closure <日志.jsonl>
```

## 边界

- 页面只在浏览器本地解析日志。
- 页面不上传日志、不调用模型、不创建业、不修改运行库。
- 页面展示的是“镜像/投影”，不是运行库真相源。
