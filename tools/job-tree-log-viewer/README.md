# 金箍业树日志查看器

这是一个只读静态网页，用于加载金箍 JSONL 运行日志，并按事件顺序重放业树生长、校验、修复、反馈和闭环状态。

## 使用方式

1. 在浏览器中打开 `tools/job-tree-log-viewer/index.html`。
2. 点击“加载 JSONL 日志”。
3. 选择一次金箍运行生成的 `.jsonl` 日志文件。
4. 使用“下一步”“下一关键”“播放”“回到开始”“跳到最终状态”查看业树投影。

## 边界

- 页面只在浏览器本地解析日志。
- 页面不上传日志、不调用模型、不创建业、不修改运行库。
- 页面展示的是“镜像/投影”，不是运行库真相源。
